## Work this project builds on

Each entry says how it is used. Entries are added when their material
enters the repository, not before.

| Project | Licence | Use |
| --- | --- | --- |
| [AsobiCodes/rac-rs](https://github.com/AsobiCodes/rac-rs) | GPL-3.0 | Design reference for the recompiler and runtime architecture (no code copied yet) |
| [TheOnlyZac/sly1](https://github.com/TheOnlyZac/sly1) | CC0-1.0 | Sly 1 function addresses and names (`games/sly1/symbols.tsv`, from `config/symbol_addrs.txt`) |
| [menaman123/NativeEE](https://github.com/menaman123/NativeEE), [Sly-2-Recomp](https://github.com/menaman123/Sly-2-Recomp) | MIT, Apache-2.0 | Reference for Sly 2 internals (no code copied yet) |
| [PCSX2](https://github.com/PCSX2/pcsx2) | GPL-3.0-or-later | Reference for hardware behaviour; oracle for tests. Its VU opcode tables (`pcsx2/DebugTools/DisVUmicro.h`) are transcribed as test data in `crates/ps2-isa/src/vu/tests.rs`; its GS local-memory swizzle tables (`pcsx2/GS/GSTables.cpp`) are ported, generated by a script, in `crates/ps2-gs/src/tables.rs`. `crates/ps2-gs/src/dump.rs` writes its GS dump format (read for the layout, no code copied), and `tools/pcsx2-frames.sh` uses its debug frame dumps |
| [ps2dev/ps2sdk](https://github.com/ps2dev/ps2sdk) | AFL-2.0 | Linked into our test programs (`conformance/conformance.elf`, `conformance/iop/`: start-up code, EE libraries, IOP import tables); read for facts, not copied: its syscall list (EE kernel call names) and its IOP library headers (function numbers, structures, error codes of the IOP kernel sly-rs emulates) |
| [ps2dev toolchain](https://github.com/ps2dev/ps2dev) (GCC, binutils) | GPL-3.0 with the GCC Runtime Library Exception | Builds `conformance/conformance.elf`; the runtime library linked in is covered by the exception |
| [Decompollaborate/rabbitizer](https://github.com/Decompollaborate/rabbitizer) | MIT | Test-only dependency: the independent R5900 decoder `ps2-isa` is checked against |

Projects read for facts only, never copied: ProjectCane and
Komasia/sly2-decomp (no licence), OpenThievius/sly1-decomp (AGPL-3.0). The
two decompilations' function lists were compared with ours locally as a
check; they are not in this repository.
The full survey is in [docs/research/landscape.md](docs/research/landscape.md).
